# Power BI report artifact

Bundled report: [Telco_Revenue_Risk_Dashboard.pbix](Telco_Revenue_Risk_Dashboard.pbix).

Desktop cross-filtering was tested and verified by the project author. The complete editable Power BI model is included in this directory. Open it in Power BI Desktop, update local CSV source paths in Power Query, and refresh before comparing totals. See the [setup guide](../docs/power_bi_setup.md) for model reproduction and refresh details. The semantic model has not been independently inspected here. The normal PBIX is intentionally allowed by `.gitignore`; only autosaves, temporary variants, and local caches are ignored. Review embedded data and source connection details before publishing the binary. Do not put credentials or raw private customer data in a public report.
